# ICT251 Activity 3 - Interactive Personal Website

A responsive personal portfolio built with HTML5, CSS3 and JavaScript.

## Live Site
https://your-site.onrender.com

## Four JavaScript Features
1. Contact form validation and preview
2. Gallery viewer (Previous / Next)
3. Project search / filter with reset
4. Light / dark theme switch

## How to Test
- Form: submit empty, spaces-only and invalid email → see errors. Valid input shows a preview.
- Gallery: click Next past the last photo → wraps to the first.
- Filter: type "xyz" → "No projects match your search." Click Reset to restore.
- Theme: toggle and reload — preference is saved.
